# 🚀 BISync - AI-Powered Compliance Assistant

BISync is a full-stack, AI-driven compliance verification system designed to streamline standard checks, automate ISI mark detection via computer vision, and query Bureau of Indian Standards (BIS) regulations instantly.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** FastAPI, Python, Pydantic, SQLAlchemy, PyMySQL
- **Vector Database:** ChromaDB (for semantic AI rule searching)
- **Deployment Ready:** Vercel (Frontend) & Render/Railway (Backend)

---

## 🌟 Core Features

1. **AI Vision Scanner:** Real-time camera stream or image upload to detect and verify compliance marks instantly.
2. **ChromaDB Vector Search:** Semantic search engine to query complex BIS rules and standards in milliseconds.
3. **Audit & Compliance Reporting:** Instant generation and download of official compliance verification reports.
4. **Verification History Log:** Real-time tracking of recent queries and scan results.
